# Contracts: Market Data and Risk Assessment System (skeleton)

This file describes every public function in the skeleton. Every body raises
`NotImplementedError`, so no function has working behaviour yet. Each entry says
what the function will do once implemented.

Spec references use the IDs from spec.md (FR, NFR, AC).

## 0. Conventions

- **Injection.** Each module is a dataclass. Its fields are the dependencies it
  receives. Constructors only store those fields. Dependencies are never imported
  as globals, so the clock is always injected as `now: Callable[[], datetime]`.
- **Time.** All timestamps are timezone-aware UTC. The server assigns
  `received_at` (ingestion) and every audit timestamp (Audit Log). Vendor and trade
  timestamps are stored as given.
- **Money and quantities.** `Decimal`, never `float`.
- **IDs.** Strings. Generated by the component that creates the record. The
  generator is not part of the skeleton.
- **Optimistic concurrency (FR-004).** Alerts and mitigation plans carry a
  `version`. A write passes `expected_version`. If the version has changed, the
  write fails with a conflict error and nothing is changed. This is how "the
  second action is rejected".
- **Error types.** Each module defines its own error types. The skeleton does not
  yet map them to HTTP status codes. Only the 501 mapping exists. A proposed mapping
  for the implementation phase is in section 3.
- **Authorization.** Access Control checks every request for system data (NFR-002).
  Each DashboardApi method lists the roles it allows. The check is made before any
  module is called.
- **Read-only.** The Audit Log has no update or delete operation (FR-005, NFR-001).

## 2. REST API contracts

Every route calls one method on `DashboardApi` (`app/dashboard_api.py`). Every
route currently returns HTTP 501 with:

```json
{"error": "not_implemented", "message": "DashboardApi.<method> is not implemented"}
```

"Roles" is the set that the DashboardApi method will allow. "Auth" is the
authentication requirement. Unauthenticated routes are health checks and login only.
